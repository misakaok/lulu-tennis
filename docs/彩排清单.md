# 周末比赛彩排清单

用一场「测试活动」把比赛当天要用的流程完整跑一遍。每一步写明了操作和应该看到的结果。

## 执行规则（给执行的人 / Codex）

- **只操作，不改代码，不改数据库，不改云函数配置。** 遇到失败就记下来，继续做后面能做的步骤，最后统一汇报。
- 测试活动的名字必须以「测试」开头，**不要碰任何真实活动**。
- 需要几个账号（下面称为 **发起人 / 球员 A / 球员 B**，双打再加 **球员 C、D**）。可以用开发者工具的「多账号调试」，或者用体验版在不同手机上登录。**如果你只能操作一个账号，先停下来问用户，由用户在手机上配合。**
- 每一步记录：✅ 通过 / ❌ 失败。失败时记下：
  1. 界面上的提示文字（原文）或截图；
  2. 开发者工具 Console 里的红色报错；
  3. 云开发控制台 → 云函数 → tennis → 日志里，同一时间的报错。

## 第 0 步：准备

| # | 操作 | 应该看到 |
|---|---|---|
| 0.1 | 运行 `node tests/run.js` | 全部通过（0 失败） |
| 0.2 | **先截图「排行」页**（部署前的排名，用来和部署后对比） | — |
| 0.3 | 问用户这次要不要部署 1.0。要的话，先按 `docs/项目进度.md` 第三节的部署说明部署云函数并上传小程序 | 部署成功 |
| 0.4 | 问用户周末的赛制：**单打 / 双打**，**淘汰赛 / 小组赛 / 小组赛＋淘汰赛**，大概几人 | 下面的测试活动用同样的赛制 |
| 0.5 | 确认几个测试账号都已经是正式成员，都设置了头像和昵称 | 「我的」页能看到自己的资料 |

## 第 1 步：创建球友活动和报名

| # | 账号 | 操作 | 应该看到 |
|---|---|---|---|
| 1.1 | 发起人 | 活动 → 创建球友活动。名称填「测试-周末彩排」，赛制和周末一样，填日期、时间、场地，在地图上选一个位置，填联系人，选「开放报名」 | 提示「已创建」，进入活动详情页，信息都正确 |
| 1.2 | 发起人 | 活动详情 → 编辑，改一下场地名，保存 | 提示「已保存」，详情页显示新的场地 |
| 1.3 | 球员 A | 打开测试活动，点「我要报名」（双打选球员 C 当搭档） | 提示「报名成功」，报名名单里有自己（双打还有搭档），显示头像、昵称、场数 |
| 1.4 | 球员 B | 同样报名（双打选 D 当搭档） | 报名成功 |
| 1.5 | 球员 B | 点「取消报名」，再重新报名一次 | 取消成功，重新报名也成功 |
| 1.6 | 球员 A | 再点一次报名（或用双打选一个已报名的人当搭档） | 不会出现两条报名；选已报名的搭档会提示「已经报名了」 |
| 1.7 | 球员 A、B | 活动详情里查看联系人 | 报名后能看到完整的联系方式 |

## 第 2 步：生成签表（最关键）

| # | 账号 | 操作 | 应该看到 |
|---|---|---|---|
| 2.1 | 发起人 | 点「截止报名，生成签表 / 分组」→ 抽签 → 保存 | 提示「已生成」，签表 / 分组 / 赛程显示正常 |
| 2.2 | 发起人 | 再进一次生成页面，重新抽签并保存（这时还没有比分） | 可以重新生成 |
| 2.3 | 球员 A | 在活动页切到「我的活动」 | 能看到测试活动；赛程里能看到自己的场次 |
| 2.4 | 球员 A | 点「取消报名」 | 提示要走「申请退赛」（签表生成后不能直接取消） |

> ❗ 2.1 如果失败（比如提示「签表不对」「参赛名单不对」「签位不对」），**这是最重要的问题**，一定要记下原文。

## 第 3 步：录分和确认

| # | 账号 | 操作 | 应该看到 |
|---|---|---|---|
| 3.1 | 球员 A | 在签表 / 赛程里点自己和 B 的那一场，录一个比分（比如 4:2），提交 | 提示成功；签表上显示比分；淘汰赛的晋级者进入下一轮 |
| 3.2 | 球员 B | 「我的 → 待办」 | 「待我确认的比分」里有这一场 |
| 3.3 | 球员 B | 点进去，点「确认比分」 | 双方都显示已确认 |
| 3.4 | 球员 A | 赛程里再点这一场，试着改比分 | 提示已经双方确认，要「申请修改比分」 |
| 3.5 | 球员 B | 比赛详情 → 申请修改比分，填一个新比分和原因 | 提示已提交 |
| 3.6 | 球员 A | 待办 / 比赛详情里看到这条申请，点「拒绝」 | 申请消失，比分不变 |
| 3.7 | 发起人 | 录另一场（如果有），或替 A、B 再录一场 | 发起人可以代录任何一场 |
| 3.8 | 任意 | 打开「战绩」页和「排行」页 | 测试比分出现在战绩里；排行正常显示，没有报错 |
| 3.9 | 任意 | 点 A 的头像进入球员主页 | 场数、胜负、等级都有数字，近期比赛里有测试比分 |

## 第 4 步：退赛

| # | 账号 | 操作 | 应该看到 |
|---|---|---|---|
| 4.1 | 球员 B | 活动详情 → 申请退赛，填原因 | 提示「已提交，等发起人处理」 |
| 4.2 | 发起人 | 待办里或活动详情里看到退赛申请，点「拒绝」并填原因 | 申请消失，B 仍在签表里 |

（不要真的批准退赛，以免把测试数据弄复杂。）

|---|---|---|---|
| 5.1 | 球员 A | 活动相册 → 上传 1～2 张照片 | 显示「审核中」，过一会儿变成可见 |

## 第 6 步：清理

| # | 账号 | 操作 | 应该看到 |
|---|---|---|---|
| 6.1 | 发起人 | 进入每一场测试比分的比赛详情 →「撤销这场赛果」，填原因 | 撤销成功；战绩、排行里不再有测试比分 |
| 6.2 | 发起人 | 活动详情 → 删除 | 活动列表里不再显示测试活动 |
| 6.3 | 任意 | 再看「排行」页，和 0.2 的截图对比 | **排名、场数、等级和彩排前完全一样** |
| 6.4 | 发起人 | 云开发控制台 → 存储 →「event-photos/<测试活动ID>/」 | 测试照片已删除（如果做了第 5 步） |
