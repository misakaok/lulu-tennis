## 云端和兼容路径

- 各种原因云端只接受固定选项（不需要内容检测）。手动比赛名称、修改的昵称、准入和接受邀请时的称呼、旧版小程序手动新增的球员、提交的签表名单调用现有 `msgSecCheck`；只接受明确的 `pass`。违规、待人工复核、返回格式异常、接口无权限、报错和超时都拒绝写入。
- 身份仍取 `cloud.getWXContext().OPENID`。没有扩大网关、管理员或活动发起人的权限。
- 小组名称由固定组号生成，不接受客户端自定义小组文字。
- `publicDraw` 和 `publicMatch` 保留手动名称，过滤场地文字、地图名称 / 地址、公共退赛原因及比分记录里的处理原因；原始原因仍在服务端留档，比分、统计身份和晋级规则不变。
- `dataset`、分页网关、活动详情、旧云函数回退和本机缓存使用一致的展示处理。
- 云函数里停用的相册、评价、简介、关注等兼容操作按项目约定保留；全部注册页面和组件不调用它们，没有恢复这些前端入口。
